## 1.1 强化学习概述

### 1.1.1 什么是强化学习

**强化学习（reinforcement learning，RL）**讨论的问题是：**智能体（agent）怎么在复杂、不确定的环境（environment）中最大化它能获得的奖励**。

如图 1.1 所示，强化学习由两部分组成：智能体和环境。在强化学习过程中，智能体与环境一直在交互：

1. 智能体从环境中获取当前**状态（state）**；
2. 智能体根据该状态输出一个**动作（action）**，也称为**决策（decision）**；
3. 该动作在环境中被执行；
4. 环境根据智能体采取的动作，返回**下一个状态**以及当前动作带来的**奖励（reward）**。

智能体的目的就是尽可能多地从环境中获取奖励。

> **关键要点**：强化学习的核心是**交互学习**——智能体不是从固定的数据集中学习，而是在与环境持续交互的过程中，通过试错来发现哪些动作能带来更多奖励。

### 1.1.2 强化学习与监督学习的区别

理解强化学习最有效的方式之一，就是将其与我们已经熟悉的监督学习进行对比。

以图片分类为例，如图 1.2 所示，**监督学习（supervised learning）**假设我们有大量被标注的数据（如汽车、飞机、椅子的图片），这些图片满足独立同分布（i.i.d.），即它们之间没有关联关系。训练时，我们把正确的标签信息传递给神经网络；当神经网络做出错误预测时，我们直接告诉它正确标签是什么，并通过损失函数和反向传播来修正网络。

<div align=center>
<img width="650" src="../img/ch1/1.2.png"/>
</div>
<div align=center>图 1.2 监督学习</div>

监督学习有两个基本假设：
* 输入的数据（标注的数据）应是没有关联的（独立同分布）；
* 我们需要告诉学习器正确的标签是什么，这样它才能通过正确的标签来修正自己的预测。

> 通常假设样本空间中全体样本服从一个未知分布，我们获得的每个样本都是独立地从这个分布上采样获得的，即**独立同分布（independent and identically distributed，简称 i.i.d.）**。

然而，在强化学习中，监督学习的这两个假设都无法满足。以雅达利（Atari）游戏 Breakout 为例（图 1.3），这是一个打砖块游戏，玩家控制木板左右移动来反弹小球消除砖块：

- **不满足独立同分布**：智能体得到的观测（observation）不是独立的，上一帧与下一帧之间有非常强的连续性——它们是相关的时间序列数据；
- **没有即时反馈（标签）**：游戏不会告诉我们哪个动作是"正确动作"。比如现在把木板往右移，球可能只是往上或往左弹了一点，我们并不会得到即时反馈说"这个动作是对的"。

如图 1.4 所示，强化学习的训练数据就是一个玩游戏的过程。从第 1 步开始，我们采取一个动作，得到训练数据是一个序列。在第 3 步时，我们把这个序列输入网络，希望网络输出一个动作，但是我们**没有标签**来说明这个动作是正确还是错误的——必须等到游戏结束（可能 10 秒之后）才知道结果。这就是**延迟奖励（delayed reward）**问题，也是强化学习困难的核心原因之一。

**强化学习与监督学习的核心区别总结**：

| 维度 | 监督学习 | 强化学习 |
|------|---------|---------|
| **数据特性** | 独立同分布（i.i.d.）样本 | 序列数据（sequential data），有时间关联 |
| **反馈方式** | 每个样本都有正确标签，即时反馈 | 只有奖励信号（reward signal），且是延迟的 |
| **学习方式** | 从给定的"输入-输出"映射中学习 | 通过试错探索（trial-and-error exploration）发现最优动作 |
| **监督者** | 有明确的监督者（标签提供者） | 没有监督者，只有环境的奖励信号 |
| **核心挑战** | 过拟合、数据质量 | 探索与利用权衡、延迟奖励、数据相关性 |

进一步总结强化学习的关键特征：

1. **试错探索**：智能体通过不断尝试不同动作来获取对环境的理解；
2. **延迟奖励**：智能体从环境获得的是延迟的奖励信号，而非即时指导；
3. **时间至关重要**：数据是时间相关的序列（sequential data），而非独立同分布——数据关联性会使训练非常不稳定；
4. **动作影响后续数据**：智能体的动作会改变环境状态，进而影响它随后收到的数据。如果智能体在训练过程中不稳定，采集到的数据就会很糟糕，整个训练可能失败。因此**如何让智能体的动作稳定提升**是强化学习的核心问题之一。

通过对比 Pong 游戏（图 1.5、图 1.6）可以更直观地理解两者差异：在监督学习中，我们可以直接告诉智能体"这一帧应该往上移动"；但在强化学习中，我们不知道正确标签，只能让智能体不断尝试，直到游戏结束，再根据最终结果来训练。

### 1.1.3 强化学习的应用潜力

为什么我们如此关注强化学习？一个非常重要的原因是：**强化学习得到的模型可以拥有超越人类的表现**。

监督学习的训练数据由人类标注（如 ImageNet），因此监督学习算法的性能上限（upper bound）理论上就是人类的表现——标注结果决定了它永远不可能超越人类。但强化学习通过在环境中自主探索，有巨大的潜力突破这一限制。最具代表性的例子是 DeepMind 的 AlphaGo，它通过强化学习击败了人类顶尖围棋棋手。

**更多强化学习应用实例**（图 1.11）：

- 🎮 **游戏领域**：雅达利游戏、围棋（AlphaGo）、星际争霸等
- 🦿 **机器人控制**：DeepMind 研发的走路智能体、机械臂抓取、OpenAI 的机械臂翻魔方
- 📈 **金融交易**：股票买卖策略优化
- 🎬 **动画制作**：训练智能体完成穿衣服等精细操作
- 🦌 **自然界类比**：羚羊幼崽通过试错学会站立和奔跑，本质上也是强化学习

## 1.2 强化学习核心概念

在深入理论之前，必须先把几个基本术语的定义和关系搞清楚。

### 1.2.1 智能体与环境的交互循环

强化学习研究的是**智能体与环境交互**的问题。如图 1.12 所示，交互形成一个闭环：

1. 智能体将**动作**输出给环境；
2. 环境收到动作后，执行下一步；
3. 环境将**下一个观测**和该动作带来的**奖励**返还给智能体；
4. 智能体利用这些反馈来改进自己的决策。

<div align=center>
<img width="550" src="../img/ch1/1.18.png"/>
</div>
<div align=center>图 1.12 智能体和环境</div>

这种交互产生的大量观测数据（状态、动作、奖励的序列）就是智能体学习的原材料。

### 1.2.2 状态与观测

> **状态（state）**是对世界的完整描述，不会隐藏任何世界信息。
> **观测（observation）**是对状态的部分描述，可能遗漏一些信息。

在深度强化学习中，我们几乎总是用实值向量、矩阵或更高阶的张量来表示状态和观测。例如：
- 用 RGB 像素矩阵表示一个视觉观测；
- 用机器人关节的角度和速度表示一个机器人的状态。

环境有自身的状态更新函数 $s_{t}^{e}=f^{e}(H_{t})$，智能体内部也有自己的状态更新函数 $s_{t}^{a}=f^{a}(H_{t})$。这两者的关系决定了环境的**可观测程度**：

- **完全可观测（fully observed）**：智能体的状态与环境状态等价，即 $o_t = s_t^e = s_t^a$。此时强化学习可建模为**马尔可夫决策过程（MDP）**。
- **部分可观测（partially observed）**：智能体只能看到环境的部分信息。比如玩 black jack 时只能看到牌面上的牌，玩雅达利游戏时只能看到当前屏幕的一帧。此时强化学习被建模为**部分可观测马尔可夫决策过程（POMDP）**。

> 💡 **补充理解**：POMDP 是 MDP 的泛化——它保留了马尔可夫性质（下一状态仅取决于当前状态和动作），但假设智能体无法直接感知完整的环境状态，只能通过观测来"猜测"真实状态。一个常用的 POMDP 形式化定义为七元组 $(S, A, T, R, \Omega, O, \gamma)$，其中 $S$ 为隐状态空间，$\Omega$ 为观测概率，$O$ 为观测空间。

### 1.2.3 动作空间

不同的环境允许不同类型的动作。**动作空间（action space）**是指给定环境中有效动作的集合。

- **离散动作空间（discrete action space）**：动作数量是有限的，如雅达利游戏、围棋。例如走迷宫机器人只有 {东、南、西、北} 4 种移动方式；
- **连续动作空间（continuous action space）**：动作是实值向量，如在物理世界中控制机器人时，移动方向可以是 360 度中的任意角度。

> 动作空间的类型直接影响我们可以使用哪类强化学习算法。基于价值的方法（如 Q-learning）通常需要离散动作空间，而基于策略的方法（如策略梯度）可以处理连续动作空间。

### 1.2.4 奖励与回报

**奖励（reward）**是环境给出的一种**标量反馈信号（scalar feedback signal）**，用于评价智能体在某一步的表现。

强化学习的目标就是**最大化智能体可以获得的期望累积奖励（expected cumulative reward）**。不同环境中的奖励形式各异：
- 象棋：最终赢棋得正奖励，输棋得负奖励；
- 股票交易：由盈亏金额决定；
- 雅达利游戏：游戏分数的增减，奖励本身的稀疏程度决定了游戏的难度。

**奖励的关键特征**：
- **延迟性**：当前动作的奖励可能要在很久之后才能体现出来；
- **稀疏性**：很多环境中大部分步骤奖励为 0，只有关键步骤才有非零奖励（如围棋只在终局有奖励）。

**回报（return）**是强化学习优化的真正目标：在时刻 $t$，回报 $G_t$ 定义为未来所有奖励的折扣加权和：

$$
G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}
$$

其中 $\gamma \in [0, 1]$ 是**折扣因子（discount factor）**，表示我们对近期奖励和远期奖励的权衡：
- $\gamma = 0$：只关心即时奖励（短视）；
- $\gamma \rightarrow 1$：非常关心远期奖励（远见）；
- 引入折扣因子的直观理解：现在拿到 100 块钱比 10 天后拿到 100 块钱更值钱（可以存入银行获得利息）。

> 💡 **补充说明**：对于回合制任务（episodic tasks），回报就是有限步奖励的折扣和；对于连续任务（continuing tasks），如果不使用折扣因子（$\gamma < 1$），回报可能发散到无穷大。

### 1.2.5 历史、状态与序列决策

在智能体与环境的交互过程中，会积累一系列数据。**历史**是观测、动作、奖励的序列：

$$
H_t = o_1, a_1, r_1, o_2, a_2, r_2, \ldots, o_t, a_t, r_t
$$

智能体在采取当前动作时会依赖于它之前得到的历史，因此整个游戏状态可以看作关于历史的函数：

$$
S_t = f(H_t)
$$

这就是**序列决策（sequential decision making）**的本质：智能体的目的不是优化单步奖励，而是选取**一系列**具有长期影响的动作来最大化累积奖励。在这个过程中，面临的核心权衡是**近期奖励与远期奖励的平衡**——现在牺牲一点短期利益，换取未来更大的收益。

## 1.3 马尔可夫决策过程（MDP）

马尔可夫决策过程是强化学习的标准数学框架，几乎所有 RL 问题都可以形式化为 MDP。

### 1.3.1 MDP 的形式化定义

一个**马尔可夫决策过程（Markov decision process，MDP）**通常用一个五元组来表示：
$$
\langle S, A, P, R, \gamma \rangle
$$

其中：
- $S$：**状态空间**（state space），所有可能状态的集合；
- $A$：**动作空间**（action space），所有可能动作的集合；
- $P$：**状态转移函数**（state transition function），$P(s' \mid s, a)$ 表示在状态 $s$ 采取动作 $a$ 后转移到状态 $s'$ 的概率；
- $R$：**奖励函数**（reward function），$R(s, a)$ 表示在状态 $s$ 采取动作 $a$ 后获得奖励的期望值；
- $\gamma$：**折扣因子**（discount factor），$\gamma \in [0, 1]$。

> **马尔可夫性质（Markov property）**：下一状态 $s_{t+1}$ 只取决于当前状态 $s_t$ 和当前动作 $a_t$，与更早的历史无关。即 $P(s_{t+1} \mid s_t, a_t) = P(s_{t+1} \mid s_0, a_0, \ldots, s_t, a_t)$。这个假设大大简化了分析和求解。

当智能体能够观察到环境的所有状态时（$o_t = s_t^e = s_t^a$），环境是完全可观测的，问题被建模为标准 MDP。

### 1.3.2 状态转移概率与奖励函数

MDP 的两个核心动态元素是：

**状态转移概率**：
$$
p_{ss'}^{a} = P\left(s_{t+1} = s' \mid s_t = s, a_t = a\right)
$$
它描述了环境在智能体采取动作 $a$ 后从状态 $s$ 转移到 $s'$ 的概率。

**奖励函数**：
$$
R(s, a) = \mathbb{E}\left[r_{t+1} \mid s_t = s, a_t = a\right]
$$
它描述了在状态 $s$ 采取动作 $a$ 后获得的即时奖励期望。

### 1.3.3 部分可观测马尔可夫决策过程（POMDP）

当智能体只能看到部分观测时，问题被建模为**部分可观测马尔可夫决策过程（Partially Observable Markov Decision Process，POMDP）**。POMDP 是 MDP 的泛化形式，形式化为七元组：

$$
(S, A, T, R, \Omega, O, \gamma)
$$

其中新增的两个元素：
- $\Omega$：**观测空间**（observation space）；
- $O(o \mid s, a)$：**观测概率**，表示在状态 $s$ 采取动作 $a$ 后观测到 $o$ 的概率；
- $S$ 是**隐变量（latent variable）**——环境真实状态对智能体不可见。

> 💡 **实例**：自动驾驶中，智能体只能通过传感器（摄像头、激光雷达等）获取有限的环境信息，无法直接获取道路上所有物体的精确位置和速度——这是一个典型的 POMDP。

### 1.3.4 轨迹、回合与试验

在强化学习中，智能体与环境的一次完整交互序列称为一条**轨迹（trajectory）**，即状态和动作的序列：

$$
\tau = \left(s_0, a_0, s_1, a_1, s_2, a_2, \ldots\right)
$$

如图 1.8 所示，**预演（rollout）**指从当前帧开始，对动作进行采样，生成完整的游戏过程。

一场完整的游戏过程称为一个**回合（episode）**或**试验（trial）**。回合从初始状态开始，到终止状态（如游戏胜利、失败或达到最大步数）结束。智能体通过观测序列和最终奖励（eventual reward）来学习，使自身尽可能采取能最大化最终奖励的动作。

## 1.4 强化学习智能体的组成成分

一个强化学习智能体可以包含以下一种或多种成分：

| 成分 | 作用 | 核心问题 |
|------|------|---------|
| **策略（policy）** | 决定智能体的动作 | 在当前状态下应该做什么？ |
| **价值函数（value function）** | 评估状态/动作的好坏 | 当前状态/动作能带来多少长期回报？ |
| **模型（model）** | 模拟环境的运行规则 | 如果我做了某个动作，环境会怎样变化？ |

下面逐一深入了解。

### 1.4.1 策略（Policy）

策略是智能体的动作选择机制，它是一个从状态到动作的映射函数。

**随机性策略（stochastic policy）**：
$$
\pi(a \mid s) = P\left(a_t = a \mid s_t = s\right)
$$
输入状态 $s$，输出所有可能动作的概率分布。例如在某状态下有 0.7 概率向左、0.3 概率向右，通过采样决定实际动作。

**确定性策略（deterministic policy）**：
$$
a^{*} = \underset{a}{\arg\max}\;\pi(a \mid s)
$$
直接选择概率最高的动作（在连续动作空间中定义为 $a = \mu(s)$）。

如图 1.14 所示，在雅达利游戏中，策略函数的输入是游戏的一帧画面，输出决定智能体向左或向右移动。

<div align=center>
<img width="550" src="../img/ch1/1.26.png"/>
</div>
<div align=center>图 1.14 策略函数</div>

> **为什么通常使用随机性策略？**
> 1. 学习时可以引入随机性来更好地**探索**环境；
> 2. 动作具有多样性，在多智能体博弈中使对手难以预测；
> 3. 确定性策略对同一状态总是做出相同动作，容易被对手利用。
>
> 但在一些场景（如已知最优策略的确定性环境），确定性策略也有其优势。

### 1.4.2 价值函数（Value Function）

价值函数用于评估在给定策略下某个状态（或状态-动作对）的"好坏"——即从该点出发，按照策略 $\pi$ 执行，未来可以获得多少期望累积奖励。

**状态价值函数（V 函数）**——在状态 $s$ 遵循策略 $\pi$ 的期望回报：
$$
V_{\pi}(s) \doteq \mathbb{E}_{\pi}\left[G_t \mid s_t = s\right] = \mathbb{E}_{\pi}\left[\sum_{k=0}^{\infty} \gamma^k r_{t+k+1} \mid s_t = s\right], \quad \text{对于所有 } s \in S
$$

**动作价值函数（Q 函数）**——在状态 $s$ 采取动作 $a$，之后遵循策略 $\pi$ 的期望回报：
$$
Q_{\pi}(s, a) \doteq \mathbb{E}_{\pi}\left[G_t \mid s_t = s, a_t = a\right] = \mathbb{E}_{\pi}\left[\sum_{k=0}^{\infty} \gamma^k r_{t+k+1} \mid s_t = s, a_t = a\right]
$$

> **V 函数与 Q 函数的关系**：$V_{\pi}(s) = \sum_{a} \pi(a \mid s) Q_{\pi}(s, a)$，即状态的价值等于在该状态下按策略对所有动作的 Q 值加权平均。

Q 函数是强化学习中最核心的学习目标之一——一旦我们学到了最优 Q 函数 $Q^{*}$，最优动作就是 $\arg\max_a Q^{*}(s, a)$。

### 1.4.3 模型（Model）

模型描述环境的动态特性，由两部分构成：

**状态转移概率**：
$$
p_{ss'}^{a} = P\left(s_{t+1} = s' \mid s_t = s, a_t = a\right)
$$

**奖励函数**：
$$
R(s, a) = \mathbb{E}\left[r_{t+1} \mid s_t = s, a_t = a\right]
$$

模型使智能体可以"想象"动作的后果而不必实际执行——这在**规划（planning）**中至关重要。

> 当我们同时拥有策略、价值函数和模型这三个组成部分，并将其整合在 MDP 框架中时，就形成了一个完整的决策系统。

## 1.5 强化学习智能体的分类

根据智能体学习的对象和使用的方法，可以从多个维度进行分类。

### 1.5.1 基于价值的智能体 vs 基于策略的智能体 vs 演员-评论员智能体

| 类型 | 学习什么 | 如何决策 | 适用场景 | 代表算法 |
|------|---------|---------|---------|---------|
| **基于价值的智能体（value-based agent）** | 显式学习价值函数（Q 函数或 V 函数） | 从价值函数中隐式推导策略（如 $\epsilon$-greedy 选最大 Q 值动作） | 离散动作空间 | Q-learning、SARSA、DQN |
| **基于策略的智能体（policy-based agent）** | 直接学习策略函数 $\pi(a \mid s)$ 或 $\mu(s)$ | 直接输出动作概率或动作值 | 连续动作空间、随机策略场景 | Policy Gradient、REINFORCE、PPO |
| **演员-评论员智能体（actor-critic agent）** | 同时学习策略（演员）和价值函数（评论员） | 演员提议动作，评论员评估好坏，两者交互优化 | 兼有两者的优点，是目前主流 | A3C、SAC、TD3 |

**深度对比**：

- 基于价值的方法需要为每个动作估计 Q 值，当动作空间很大或是连续的时候难以处理；但它可以充分利用历史数据（off-policy 学习），样本效率较高；
- 基于策略的方法可以直接处理连续动作和随机策略，但通常样本效率较低、方差较大；
- 演员-评论员方法结合两者优势，用价值函数来降低策略梯度的方差，加速学习。

### 1.5.2 有模型强化学习 vs 免模型强化学习

| 维度 | 有模型强化学习（model-based RL） | 免模型强化学习（model-free RL） |
|------|--------------------------------|-------------------------------|
| **是否对真实环境建模** | 是，构建虚拟世界模拟环境动态 | 否，直接与真实环境交互 |
| **核心特点** | 学习或已知状态转移函数和奖励函数 | 直接学习策略和/或价值函数 |
| **数据效率** | 较高，可在虚拟世界中"想象"训练 | 较低，需大量真实交互数据 |
| **泛化能力** | 受模型误差限制（虚拟世界与真实环境有差异） | 通常泛化性更好 |
| **计算开销** | 需额外维护和更新环境模型 | 计算相对简单 |
| **典型应用** | AlphaZero（已知完美模型）、机器人控制 | 雅达利游戏、AlphaGo（免模型部分） |

**有模型学习的独特优势**：拥有"想象能力"。智能体可以在虚拟世界中预测将要发生的事，提前规划最优策略，而不必在真实环境中冒险试错。

**为什么目前大多数深度 RL 方法采用免模型学习？**
1. 免模型方法更简单直观，有丰富的开源资料（如 AlphaGo 系列）；
2. 目前多数研究场景（如雅达利游戏）环境是静态可描述的、状态是离散可观察的，不需要评估复杂的环境模型；
3. 有模型方法中模型误差可能导致策略偏差，在复杂环境中难以保证模型精度。

**一个实用的判断准则**：如果你能在智能体执行动作前预测下一步的状态和奖励，就可以对环境建模，采用有模型方法；否则应采用免模型方法。

## 1.6 探索与利用（Exploration & Exploitation）

探索和利用是强化学习最核心的两个问题之一。

### 1.6.1 探索-利用的基本概念

- **探索（exploration）**：尝试新的动作，了解它们能带来多少奖励。这些新动作可能带来更大的奖励，也可能一无所获；
- **利用（exploitation）**：采取已知能带来较多奖励的动作，重复执行，因为我们知道这样做能获得确定的收益。

在刚开始时，智能体不知道自己的动作会导致什么结果，只能通过试错去**探索**；学到一定经验后，它可以**利用**已知的好动作。这里面临一个核心权衡：**如何牺牲一些短期奖励来更好地理解环境，从而学到更优的长期策略？**

**生活中的例子**：
- 🍽️ **选餐馆**：利用 = 去常去的最喜欢的餐馆；探索 = 尝试一家新餐馆（可能好吃也可能踩雷）
- 📢 **做广告**：利用 = 使用当前最优的广告策略；探索 = 尝试一种新广告策略
- 🎮 **玩游戏**：利用 = 用熟练的招式（如街头霸王中"蹲在角落一直出脚"）；探索 = 尝试新招式（可能放出"大招"一击制胜）

### 1.6.2 K-臂赌博机模型

与监督学习不同，强化学习任务的最终奖励在多步动作之后才能观察到。我们先考虑最简单的情形：**最大化单步奖励**。这个简化问题对应于一个经典理论模型——**K-臂赌博机（K-armed bandit）**，也称**多臂赌博机（multi-armed bandit）**。

如图 1.23 所示，K-臂赌博机有 $K$ 个摇臂，赌徒投入一个硬币后可选择按下其中一个摇臂，每个摇臂以一定的（未知的）概率吐出硬币。赌徒的目标是最大化总奖励。

<div align=center>
<img width="300" src="../img/ch1/1.39.png"/>
</div>
<div align=center>图 1.23 K-臂赌博机图示</div>

**两种极端策略**：

| 策略 | 做法 | 优点 | 缺点 |
|------|------|------|------|
| **仅探索法（exploration-only）** | 将尝试机会平均分配给每个摇臂 | 能很好地估计每个摇臂的期望奖励 | 失去很多选择最优摇臂的机会 |
| **仅利用法（exploitation-only）** | 一直按目前平均奖励最高的摇臂 | 不会浪费机会在差的摇臂上 | 可能因估计不准而长期选择次优摇臂 |

显然，两种极端方法都无法使累积奖励最大化。**探索-利用窘境（exploration-exploitation dilemma）**的本质是：总尝试次数有限，加强探索必然削弱利用，反之亦然。要想最大化累积奖励，必须在探索和利用之间达成最优折中。

> 💡 **补充**：K-臂赌博机问题看似简单，但它抓住了探索-利用权衡的本质，是研究在线决策和不确定性下决策的基础模型。常用的折中策略包括 $\epsilon$-greedy、上置信界（UCB）、Thompson 采样等，这些思想在更复杂的 RL 算法中也被广泛借鉴。

## 1.7 学习与规划（Learning & Planning）

学习和规划是序列决策的两个基本问题。

### 1.7.1 学习（Learning）

在**学习**中，环境初始是**未知的**——智能体不知道环境如何工作（不知道状态转移概率和奖励函数）。它只能通过不断地与环境交互，逐渐改进自己的策略。

<div align=center>

学习的本质是**从经验中归纳**：通过试错来估计环境的动态特性，再根据这些估计来优化策略。

### 1.7.2 规划（Planning）

在**规划**中，环境是**已知的**——智能体被告知了环境的完整运作规则（状态转移概率和奖励函数）。它可以在不与环境进行任何实际交互的情况下，在内部进行计算和模拟，寻找最优解。智能体只需要知道当前状态，就能开始"思考"并找到最优动作序列。

### 1.7.3 学习与规划的结合

一个常见且强大的问题求解思路是：
1. **先学习环境模型**（通过交互了解环境如何工作）；
2. **再利用该模型进行规划**（在学到的模型中寻找最优策略）。

这种"先学习、再规划"的思路结合了有模型学习的优势（想象能力）和免模型学习的灵活性（无需预先知道环境），在 AlphaGo 等成功系统中得到了充分体现。

## 1.8 强化学习的历史演进

### 1.8.1 标准强化学习 vs 深度强化学习

强化学习的发展可以类比于计算机视觉的演进——从手工特征+独立分类器，到端到端的深度学习。

**标准强化学习**（如图 1.10a）：
1. 先手动设计大量特征来描述当前状态；
2. 基于这些特征训练一个分类网络或价值估计函数来做出决策。

**深度强化学习（deep reinforcement learning）**（如图 1.10b）：
- 不需要手动设计特征；
- 直接输入原始状态（如图像像素），通过神经网络同时完成特征提取和决策；
- 实现**端到端训练（end-to-end training）**，省去了特征工程（feature engineering）。

### 1.8.2 深度强化学习兴起的原因

1. **算力增长**：更多 GPU 使大规模试错成为可能；
2. **数据驱动**：通过大量尝试，智能体在环境中获得了海量信息；
3. **端到端优化**：将特征提取、价值估计和决策统一优化，得到更强的决策网络。

- **Gym Retro** 是 Gym 的进一步扩展，包含更多经典游戏。

**核心 API（5 步法）**：
1. `env = gym.make("环境名")` — 创建环境
2. `observation = env.reset()` — 初始化环境，开始新回合
3. `observation, reward, done, info = env.step(action)` — 执行一个动作，环境返回新状态、奖励、是否结束、调试信息
4. `env.render()` — 显示图形界面
5. `env.close()` — 关闭环境

> env.step() 完成了一个完整的 $S \rightarrow A \rightarrow R \rightarrow S'$ 循环。反复执行此循环并让智能体在其中学习，就能训练出高质量的 RL 模型。

### 1.9.2 强化学习代码框架

```python
import gym 
env = gym.make("Taxi-v3")          # 构建环境
observation = env.reset()           # 重置环境
agent = load_agent()                # 加载智能体（需自行实现）
for step in range(100):
    action = agent(observation)     # 智能体决策
    observation, reward, done, info = env.step(action)  # 执行动作
    if done:
        break
```

> 注意：上面的 `load_agent()` 是占位函数，仅展示框架结构。

### 1.9.3 CartPole-v0 环境详解

CartPole（倒立摆）是强化学习入门的经典环境。如图 1.26 所示：
- **目标**：控制小车左右移动，使杆保持直立；
- **动作**：0（左移）或 1（右移）；
- **观测**：4 维向量 — [小车位置, 小车速度, 杆角度, 杆顶端速度]；
- **奖励**：每存活一步 +1；
- **终止条件**：杆倾斜超过角度阈值、小车离开边界或步数超过 200。

**随机策略演示**（小车会无目的地乱跑）：
```python
import gym

env.reset()                         # 重置一个回合
for _ in range(1000):
    env.render()                    # 显示图形界面
    action = env.action_space.sample()  # 随机选取动作
    env.step(action)                # 提交动作
env.close()                         # 关闭环境
```

env.step() 返回的 4 个值：
- `observation`：当前状态（结构因游戏而异）；
- `reward`：即时奖励值；
- `done`：游戏是否结束（True 时需重置环境）；
- `info`：诊断和调试信息（评测时不能使用）。

打印 CartPole 的 observation：
```python
import gym
env = gym.make('CartPole-v0')
env.reset()
for _ in range(1000):
    env.render()
    action = env.action_space.sample()
    observation, reward, done, info = env.step(action)
    print(observation)  # 输出 4 维向量
env.close()
```

### 1.9.4 MountainCar-v0 完整实例

接下来以**小车上山（MountainCar-v0）**为例，展示一个完整的交互流程。

**查看观测空间和动作空间**：
```python
import gym
env = gym.make('MountainCar-v0')
print('观测空间 = {}'.format(env.observation_space))
print('动作空间 = {}'.format(env.action_space))
print('观测范围 = {} ~ {}'.format(env.observation_space.low,
        env.observation_space.high))
print('动作数 = {}'.format(env.action_space.n))
```

输出：
```
观测空间 = Box([-1.2  -0.07], [0.6  0.07], (2,), float32)
动作空间 = Discrete(3)
观测范围 = [-1.2  -0.07] ~ [0.6  0.07]
动作数 = 3
```

**空间类型说明**：
- `gym.spaces.Discrete(n)`：离散空间，可能取值为 n 个（MountainCar 有 3 个动作：{0, 1, 2}）
- `gym.spaces.Box(low, high, shape, dtype)`：连续空间，`low` 和 `high` 表示每个维度的取值范围（MountainCar 的观测是形状为 (2,) 的 float32 数组）

**实现简易智能体**（基于规则的，非学习的）：
```python
class SimpleAgent:
    def __init__(self, env):
        pass
    
    def decide(self, observation):  # 决策
        position, velocity = observation
        lb = min(-0.09 * (position + 0.25) ** 2 + 0.03,
                0.3 * (position + 0.9) ** 4 - 0.008)
        ub = -0.07 * (position + 0.38) ** 2 + 0.07
        if lb < velocity < ub:
            action = 2
        else:
            action = 0
        return action   # 返回动作

    def learn(self, *args):  # 学习（此处为空，非强化学习智能体）
        pass

agent = SimpleAgent(env)
```

**通用交互函数**：
```python
def play(env, agent, render=False, train=False):
    episode_reward = 0.                     # 记录回合总奖励
    observation = env.reset()               # 重置环境，开始新回合
    while True:                             # 循环直到回合结束
        if render:                          # 是否显示图形界面
            env.render()
        action = agent.decide(observation)
        next_observation, reward, done, _ = env.step(action)  # 执行动作
        episode_reward += reward            # 累积奖励
        if train:                           # 是否训练智能体
            agent.learn(observation, action, reward, done)
        if done:                            # 回合结束
            break
        observation = next_observation
    return episode_reward                   # 返回回合总奖励
```

**运行并评估**：
```python
env.seed(3)  # 设置随机种子，保证结果可复现
episode_reward = play(env, agent, render=True)
print('回合奖励 = {}'.format(episode_reward))
env.close()
# 输出：回合奖励 = -105.0
```

```python
episode_rewards = [play(env, agent) for _ in range(100)]
print('平均回合奖励 = {}'.format(np.mean(episode_rewards)))
# 输出：平均回合奖励 = -106.63
```

SimpleAgent 的平均回合奖励约 $-106$，而 MountainCar-v0 的解决标准是连续 100 回合平均奖励大于 $-110$。所以这个基于规则的智能体勉强算是"解决"了该任务。

### 1.9.5 评估标准与常用环境

**学术界约定**：
- 测试智能体性能时，一般关注**连续 100 个回合的平均回合奖励**；
- 有些任务指定了参考奖励值，超过该值即认为任务"被解决"；
- 未指定参考值的任务，通常比较不同算法之间的相对表现。

**Gym 中的经典控制问题**（图 1.25）：
- **Acrobot**：双连杆机器人立起来
- **CartPole**：小车控制杆保持平衡
- **MountainCar**：小车前后移动到达旗帜位置

这些环境简单快速（一两分钟内可见效果），非常适合用于测试和调试强化学习算法。

## 本章知识点总结

| 知识点 | 核心内容 | 所在章节 |
|--------|---------|---------|
| **RL 定义** | 智能体在环境中通过试错最大化累积奖励 | 1.1.1 |
| **RL vs 监督学习** | 序列数据 vs i.i.d.、延迟奖励 vs 即时标签、试错探索 vs 已知标签 | 1.1.2 |
| **MDP** | RL 的数学框架：$\langle S, A, P, R, \gamma \rangle$，马尔可夫性质 | 1.3 |
| **POMDP** | MDP 的泛化，智能体只能获得部分观测 | 1.3.3 |
| **策略 $\pi$** | 状态到动作的映射，分为随机性策略和确定性策略 | 1.4.1 |
| **价值函数** | V 函数（状态价值）和 Q 函数（动作价值），评估长期回报 | 1.4.2 |
| **模型** | 状态转移概率 + 奖励函数，用于规划 | 1.4.3 |
| **Value-based vs Policy-based** | 学习价值函数推导策略 vs 直接学习策略 | 1.5.1 |
| **Model-based vs Model-free** | 是否对环境建模，涉及数据效率、泛化性、想象能力 | 1.5.2 |
| **探索与利用** | 试错 vs 利用已知好动作，核心权衡问题（K-臂赌博机） | 1.6 |
| **学习 vs 规划** | 环境未知时交互学习 vs 环境已知时内部模拟 | 1.7 |
| **标准 RL → 深度 RL** | 手工特征 + 分类器 → 端到端神经网络 | 1.8 |
| **Gym 实践** | `make → reset → step → render → close` 循环 | 1.9 |
